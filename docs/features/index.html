核心特性

只专注一件事，把它做到极致（Do one thing and do it well）。QuicProxy 从头编写，在性能、内存、能耗、安全性与易用性之间不断权衡。

Rust 编写​

QuicProxy 的核心完全使用 Rust（2024 Edition）编写，同一套核心编译到 Windows、Android、iOS、Linux 与软路由。

特性带来的好处
所有权与借用检查编译期消除空指针、数据竞争与缓冲区溢出
无 GC、零成本抽象没有垃圾回收停顿，延迟稳定，内存占用低
Tokio 异步运行时少量线程即可承载海量并发连接
Quinn + Rustls纯 Rust 实现的 QUIC 与 TLS，不依赖 OpenSSL

全程零延迟​

对于一条需要代理的 TCP 连接，不同方案的建连开销如下：

方案建立 / 恢复连接额外开销
TCP 方案（如 Trojan）TCP 三次握手 + TLS 握手2.5 RTT
其他 QUIC 方案（如 Hysteria2）复用已有 Connection 无需 RTT，但 Connection 中断后需重建1 RTT
ShadowquicQUIC Connection Early Data，即使 Connection 断开也能直接恢复0 RTT

弱网高可用：尤其适合网络经常变化的场景，例如高铁上基站频繁切换时，Shadowquic 可以丝滑切换，用户几乎感受不到重连卡顿。

自动智能分流​

无需手写任何规则，导入订阅即可自动分流：

  • 自动区分中国大陆与海外：中国大陆网站直连，海外网站走代理。
  • 港澳台按海外处理：“中国大陆”不包括香港、澳门与台湾地区。
  • 精确识别：基于高精确度的 GeoIP，准确识别 Instagram、Facebook、Google 等网站，不依赖冗杂的域名列表。
  • 结果缓存：分流结果写入 KV-Cache，再次遇到同样的域名时无需重新查询 DNS 与 GeoIP，极低耗时即可完成匹配。
  • DNS 不泄露：默认启用安全 DNS，海外域名的查询不会暴露给本地运营商。
访问的网站识别为策略
instagram.com、facebook.com、google.com海外代理
香港、澳门、台湾地区网站海外代理
bilibili.com、taobao.com中国大陆直连

UDP 友好​

Full Cone 且使用 UDP Extension，解决了代理 QUIC 速度慢等历史遗留问题。UDP 数据加密且无序传输，更符合 UDP 本身的特点，对游戏与语音更友好。

低内存​

去掉不必要的功能，回归本质。即使开启 TUN，在日常重度使用中内存也几乎不超过 20MB，持续保持在苹果 50MB 限制之下。

全平台​

Windows、Android、iOS、Linux（有无 GUI 皆可）与软路由均已支持，macOS 即将发布。所有平台共用同一套核心。
