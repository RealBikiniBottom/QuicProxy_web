搭建自己的节点

在 VPS 上搭建 QuicProxy 节点，生成订阅链接供客户端使用。无需域名，无需证书。

一键搭建​

curl -fsSL https://raw.githubusercontent.com/RealBikiniBottom/QuicProxy/master/server_install.sh | sudo bash

脚本会交互式询问需要启用的协议，然后自动完成安装。

可选协议​

协议传输层适用场景
shadowquic（QUIC + JLS）UDP延迟最低，适合游戏 / 视频
anytls（insecure TLS）TCP伪装 TLS，抗封锁
trojan（TLS）TCP标准 Trojan，通用性强

脚本做了什么​

  1. 下载最新的 quicproxy 二进制。
  2. 生成随机凭据。
  3. 自动检测端口和公网 IP（支持 IPv4 / IPv6）。
  4. 写入服务端配置 server.json5（含 observe / api / subscription）。
  5. 注册 systemd 服务并启动。
  6. 输出订阅链接（Core API 订阅 + 直连节点）与二维码。
# 查看订阅链接
cat /opt/quicproxy/subscription.txt

# 服务管理
systemctl status   quicproxy
systemctl restart  quicproxy
journalctl -u quicproxy -f

订阅​

脚本会在配置中启用核心 API 与 observe，并打印一个 Core API 订阅地址：

http://<公网IP>:<API端口>/sub?username=<用户名>&password=<密码>

该地址可直接导入客户端，脚本也会通过 Core API 渲染二维码。节点链接由各 inbound 动态生成，subscription-userinfo 响应头会实时上报该用户已用流量；默认不限流量、不限时间，但持续统计耗费流量。

如需多用户、对外公网地址或 IPv4 / IPv6 双栈下发，参见 机场主 API。

服务端配置​

安装后会在 /opt/quicproxy/server.json5 自动生成配置，可手动编辑后重启：

vim /opt/quicproxy/server.json5
systemctl restart quicproxy

关键配置项：入站的用户名密码、端口、TLS / SNI 设置，以及 subscription 的对外地址。

目录结构​

/opt/quicproxy/
├── quicproxy            # 二进制
├── server.json5         # 核心配置
├── subscription.txt     # 订阅链接
└── .core_api            # Core API 密码与端口

卸载​

systemctl stop quicproxy
systemctl disable quicproxy
rm -f /etc/systemd/system/quicproxy.service
systemctl daemon-reload
rm -rf /opt/quicproxy
