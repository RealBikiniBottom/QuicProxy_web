Built with Rust

Built from scratch in Rust

The core is written entirely in Rust (2024 edition): memory and thread safety are guaranteed at compile time, with no GC pauses. One core compiles to Windows, Android, iOS, Linux, and routers.

  • Memory safeOwnership and borrow checking rule out null pointers, data races, and buffer overflows at compile time.
  • No GC pausesZero-cost abstractions keep latency predictable — under 20 MB in daily use, even with TUN.
  • Async to the coreBuilt on the Tokio runtime, so a handful of threads serve a huge number of connections.
  • Pure-Rust cryptoQUIC via Quinn and TLS via Rustls — no OpenSSL dependency.

Zero RTT

Connection dropped? No waiting.

Other approaches pay extra round trips to establish or recover a connection. Shadowquic uses QUIC Connection Early Data to resume traffic immediately — even while a phone hops between cell towers on a high-speed train.

Smart Routing

Automatic smart routing, no rules to write

Traffic is split between mainland China and overseas automatically: mainland sites go direct, overseas sites go through the proxy, and Hong Kong, Macao, and Taiwan are treated as overseas. High-accuracy GeoIP precisely identifies sites like Instagram, Facebook, and Google, and results are cached so repeat visits skip the lookup.
