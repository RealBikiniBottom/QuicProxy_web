Built with Rust

用 Rust 从零打造

核心完全使用 Rust（2024 Edition）编写：编译期保证内存与线程安全，没有 GC 停顿。同一套核心编译到 Windows、Android、iOS、Linux 与软路由。

  • 内存安全所有权与借用检查在编译期消除空指针、数据竞争与缓冲区溢出。
  • 无 GC 停顿零成本抽象，延迟稳定可预期，开启 TUN 日常内存不到 20MB。
  • 全异步并发基于 Tokio 异步运行时，少量线程即可承载海量连接。
  • 纯 Rust 加密栈QUIC 基于 Quinn，TLS 基于 Rustls，不依赖 OpenSSL。
Rust 2024TokioQuinnRustlsJLS
Zero RTT

连接中断，也无需再等

其他方案在建立或恢复连接时都要付出额外的往返时间。Shadowquic 借助 QUIC Connection Early Data，即使连接断开也能立即恢复传输——在高铁上频繁切换基站，也几乎感受不到卡顿。

1 RTT

0 RTT
Smart Routing

智能分流，无需手写规则

自动区分中国大陆与海外流量：大陆网站直连，海外网站走代理，港澳台按海外处理。基于高精度 GeoIP 精确识别 Instagram、Facebook、Google 等网站，分流结果写入 KV-Cache，再次访问无需重复查询。
